# Morning report template

Short and plain. Dates and times from `date`, never from memory.

## Landed
One line each: what, the full commit hash, the gate log path.

## On a branch only
One line each: branch, full tip hash, what is left before it can land, and who must decide.

## Spend
Total against the ceiling, read the project's way; the paid steps that ran and their prices.

## Questions for the owner
Each as a choice the owner can answer in a word, with what you recommend and why. Nothing here is assumed.

## State left behind
Free disk; running sessions, servers and worktrees; anything on a remote host that is waiting for the return trip or
cleanup.
